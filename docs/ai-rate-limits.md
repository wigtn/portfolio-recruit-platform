# AI 실호출 한도 — 기준과 화면 표현

이 데모에는 OpenAI를 실제로 부르는 자리가 둘이다. 둘 다 비로그인이라
누가 얼마나 쓰는지 셀 방법이 요청의 흔적뿐이고, 그래서 한도가 곧 비용
방어선이다.

설계 배경과 결정 근거는 `docs/prd/PRD_chatbot-cost-security.md`에 있다.
이 문서는 **지금 코드에 박혀 있는 값과, 걸렸을 때 방문자가 보는 것**을
적는다. 값을 바꾸면 여기도 같이 고친다.

## 한도

| | 상담 챗봇<br>`/api/chat` | AI 자동답변<br>`/api/ai-answer` |
|---|---|---|
| IP당 | **20회 / 1시간** | **10회 / 1시간** |
| 세션 쿠키당 | **20회 / 1시간** | 없음 (IP 축만) |
| 전체 일일 | **300회** | **200회** |
| 일일 리셋 | KST 자정 | KST 자정 |

- 축은 **AND**다. IP·세션 둘 다 통과해야 1회가 허용되고, 통과할 때만
  양쪽에 자국을 남긴다. 막힌 요청은 카운트를 늘리지 않는다.
- 세션 축은 `WIGTN_COOKIE_SECRET`이 있을 때만 붙는다. 없으면 쿠키 축을
  접고 IP 축만으로 degrade한다 — 서명 없는 쿠키는 방문자가 지어낼 수
  있어서 세는 의미가 없다.
- 일일 리셋이 UTC가 아니라 KST인 이유: 한국 데모라 UTC 자정(=KST 오전
  9시)에 끊기면 업무 시작 시각에 한도가 리셋되는 꼴이 된다.
- 카운터는 **인메모리**다. 서버리스 인스턴스마다 따로 세고 콜드스타트에
  리셋된다. 데모 범위에서 감수한 한계이고, 실서비스로 가면 Redis 같은
  공유 저장소가 필요하다.

챗봇이 두 배로 넉넉한 건 대화가 이어지는 물건이기 때문이다. 세 번 묻고
막히면 그건 한도가 아니라 고장으로 읽힌다. AI 자동답변은 글 하나에
한 번 누르는 일회성이라 더 좁게 잡았다.

## 걸렸을 때 — 응답 계약

둘의 계약이 다르다. **의도된 차이다.**

```
챗봇        200 + { fallback: true, rateLimited: true, why: "ip"|"session"|"daily" }
AI 자동답변  429 + { ok: false, rateLimited: true, error: "..." }
```

챗봇은 대화가 끊기면 안 되므로 200으로 내려보내고 클라이언트가 준비된
답변으로 매끄럽게 잇는다. AI 자동답변은 일회성 생성이라 429로 끊고
클라이언트가 시드 초안 연출로 넘어간다.

## 걸렸을 때 — 방문자가 보는 것

### 상담 챗봇

말풍선 하나가 먼저 뜨고, 그 아래 준비된 답변이 이어진다.

| 원인 | 문구 |
|---|---|
| IP·세션 (`why: "ip"` / `"session"`) | 지금 실시간 답변 한도를 다 써서, 준비된 답변으로 대신할게요. 잠시 뒤에 다시 열려요. |
| 일일 총량 (`why: "daily"`) | 오늘 실시간 답변 총량을 다 써서, 준비된 답변으로 대신할게요. |

알림 말풍선(`notice: "quota"`)이라 답변과 생김새가 다르다 — 경고
아이콘이 앞에 서고 배경이 갈린다. 답변처럼 보이면 방문자가 그걸 대답인
줄 알고 읽는다.

이어지는 답변의 출처 배지는 **"준비된 답변"**이 된다(실호출이면 "AI
실시간 답변").

> **키가 없어서** 폴백인 경우(`rateLimited` 없음)는 아무 말도 하지 않는다.
> 그건 방문자 사정이 아니라 이 데모의 구성이고, 어차피 답은 나온다.

### AI 자동답변

토스트가 뜨고 시드 초안 연출로 이어진다.

| 원인 | 문구 |
|---|---|
| IP | 실호출 한도(시간당)에 도달했어요, 예시 재생으로 이어가요. |
| 일일 총량 | 오늘의 데모 생성 총량을 다 썼어요, 예시 재생으로 이어가요. |

생성 흐름(생성 → 안전 재검사 → 게시) 자체는 그대로 돌아간다. 문장이
모델에서 오는 대신 시드에서 올 뿐이라, 방문자는 기능을 끝까지 본다.

## 어디에 있나

| | 파일 |
|---|---|
| 챗봇 한도·응답 | `app/api/chat/route.ts` (`PER_IP_MAX`, `PER_SESSION_MAX`, `DAILY_MAX`, `allow()`) |
| 챗봇 화면 표현 | `components/demo/ChatWidget.tsx` (`first.rateLimited` 분기) |
| AI 답변 한도·응답 | `app/api/ai-answer/route.ts` |
| AI 답변 화면 표현 | `components/AiAnswerCard.tsx` (`res.status === 429`) |
| 익명 세션 쿠키 | `lib/demo/anon.ts` (`wigtn_anon`, HttpOnly, 서명) |

## 값을 바꿀 때

1. 라우트의 상수를 고친다.
2. 이 문서의 표를 고친다.
3. 문구를 바꿨다면 위 "방문자가 보는 것" 표도 같이 고친다.

세 곳이 어긋나면 다음 사람은 코드를 읽어야 답을 안다. 그럴 거면 문서가
없는 편이 낫다.
